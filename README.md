## 🚀 Featured AI & Computer Vision Projects

* **Tech:** YOLOv9, Python, Flask, Render
* **Description:** Real-time AI computer vision web application detecting hazardous objects from uploaded images and live webcam streams.

* **Tech:** YOLO, OpenCV, Flask, React, Tailwind CSS
